Colored border: switches to that layer (hold = while held, several taps = locks it). 2× = double tap. ▽ = same key as the base layer. Symbols follow macOS with the Spanish ISO layout.

Type with your Corne: the key you press lights up and the view switches to its layer, in the color the LEDs use. Layer keys never reach the computer, so the layer is inferred from the character you typed.

How the layers stack

    • LOWER / RAISE Hold: active while held. Several taps in a row: locks it; another tap releases it.
    • ADJUST Hold LOWER and RAISE together.
    • COLEMAK COLEMAK key in ADJUST: swaps the base layer (LOWER, RAISE and ADJUST still work on top). The same key goes back to QWERTY.
    • 2× Double tap: Esc → Caps, A → @, Ctrl → Mission Control.

    LOWER goes down and RAISE goes up from QWERTY; ADJUST is holding both. Where a layer defines no key (▽, drawn as a hole) the QWERTY key is used. COLEMAK replaces QWERTY as the base (with the KB-01 firmware): LOWER, RAISE and ADJUST still work on top of it.

    On-screen help on the Mac

    Hold ⌘Esc
    1. Hold the shortcut and the layer map appears over any app. Release it and it goes away.
    2. On the Corne: Cmd with the left thumb and Esc with the left pinky.
    3. Click KB-01 in the menu bar to pin it; click again to hide it.
    Show / hide the map

    The button needs Hammerspoon running. If nothing happens, use the shortcut or KB-01 in the menu bar.

    Install on another Mac (from the repo folder):

    brew install --cask hammerspoon
mkdir -p ~/.hammerspoon/corne
cp corne/hammerspoon/corne-overlay.lua \
   corne/corne-dojo.html ~/.hammerspoon/corne/
cat > ~/.hammerspoon/init.lua <<'EOF'
require("hs.ipc")
package.path = hs.configdir .. "/corne/?.lua;" .. package.path
corneOverlay = require("corne-overlay")
EOF
open -a Hammerspoon
